# 设备检查资料（占位示例）

> ⚠️ 本文件是占位示例，仅用于跑通 `get_checklist` 工具链路。
> 正式检查标准 / 清单在 10/21 接口冻结后由 A / C 提供，放入本目录即可被检索，不需要改代码。

## 风机异响特征速查（占位）

| 特征 | 听感 / 频谱线索 | 优先检查项 |
| --- | --- | --- |
| 摩擦异响 | 高频啸叫，频谱出现边带 | 轴承润滑、齿轮啮合 |
| 冲击异响 | 周期性"咔哒"声 | 紧固件、叶片裂纹 |
| 不平衡 | 转速频率幅值突出 | 动平衡、安装螺栓 |
| 润滑不良 | 低频沉闷声 | 油位、油质 |

## 巡检记录填写要求（占位）

- 每条异常必须附音频片段与判定依据；
- 模拟数据不得写入正式巡检报告；
- 判定存疑时升级到人工复核，不在系统内直接下结论。
